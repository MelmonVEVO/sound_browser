# Sound Browser

Game devs (me at least) when they want to add sound to their games, will sometimes use publicly available
sound effects. These come in giant directories that can be quite cumbersome to wade through.

Sound Browser is a little program that allows you to flip through all your sound files. It plays them
immediately once selected, so you can go through them quickly and find the perfect one.

Just open it up in the sound library directory and go nuts!
